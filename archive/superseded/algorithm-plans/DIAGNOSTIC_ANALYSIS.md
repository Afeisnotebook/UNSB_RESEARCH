# 诊断分析（只读，2026-08-17）

> **历史诊断：** 数据来自确定性修复前的旧轨迹，可用于理解当时的问题，不能覆盖 clean deterministic 结论。见 [FINAL_STATUS.md](./FINAL_STATUS.md)。

数据源：`refactor/_runs/diagnostics/*.jsonl` 与 `metrics_opt` 下的 `opt_*.jsonl`。
注意：DT 的 `opt_dt_*.jsonl` 曾因同名重启被 append 污染，本分析按“每 epoch 取最后一行”
去重；HJ 的 `opt_hj_*.jsonl` 干净（各 200 epoch）。

## 一、DT：drift 不是收敛信号，是发散/不稳定信号

| run | λ 退出 | drift 峰值(epoch) | 最终 PSNR |
|---|---|---:|---:|
| control（手调25） | decay 到 0 @25 | 0.545 @25 | **18.4552** |
| plateau（cap60） | 强制 0 @60 | 0.679 @38 | 17.6721 |
| window45 | decay 到 0 @45 | 0.647 @45 | 17.1409 |

结论：
- drift 在 λ 激活期间单调上升，λ 一关就回落到 0。**drift 是“当前模型相对冻结参考的漂移量”，
  不是要被最小化到 0 的目标**；它持续上升意味着正则正在“推离”参考，越久越糟。
- 因此“停止信号”不是 drift 收敛/plateau，而是**在 drift 尚未失控前退出**。手调 decay-25
  恰好在这个点上退出（drift≈0.545）。延长到 45/60 让 drift 继续涨，最终 PSNR 单调下降。
- `sb_entropy_grad_norm` 全程强噪声（0.02~5.4，且 λ 关断后 epoch26 出现尖峰），
  **无干净的单调/转折点，不适合当停止信号**。

信息量判定：**drift 有信息**（发散指示器）；**SB 熵梯度范数是噪声**。

## 二、HJ：gate 指标随 α 单调，但 PSNR 非单调

| α | gate_hit | risk_mean | risk_positive | probe_agree | PSNR |
|---:|---:|---:|---:|---:|---:|
| 0.0（纯结构） | 0.104 | 0.107 | 0.678 | 1.974 | 17.1158 |
| 0.5 | 0.125 | 0.082 | 0.861 | 1.949 | 18.6225 |
| 1.0（纯随机） | 0.143 | 0.073 | 0.998 | 1.938 | 17.4125 |

结论：
- gate_hit / risk_positive 随 α 单调上升，risk_mean 单调下降 → **gate 指标确实编码了“方向
  随机化程度”**，是有效的诊断量。
- 但 PSNR 非单调（α0 最差、α0.5 最好、α1 居中），且三组都只有 1 seed、差异在 ~1.5 dB
  噪声内。→ **gate 指标无法线性预测最终收益**；α 实验不能证明“结构方向有害”。
- 口径：`hj_alpha00` 与历史 true 差 2.3 dB 是 HJ 单 seed 方差所致（见 `FINAL_STATUS.md`），
  不是 α=0 引入 bug。

信息量判定：**gate_hit/risk 有信息（编码方向随机度）**；**它们与最终 PSNR 的关系被单 seed
噪声掩盖**。当前没有证据支持某个“梯度驱动方向”优于 edge/SSIM。

## 三、候选（Part 2B，诚实评估）

1. **DT：drift 阈值退出（低价值，本质是重参数化）**。数据只支持“drift≈0.5 前退出”，
   这与手调 decay-25 几乎等价；把固定 epoch 换成 `drift>0.5 即退` 不会有新机制收益。
   **不建议投入 GPU**。
2. **HJ：暂无数据支撑的新投影方向**。α 实验既不能证明 edge/SSIM 有害，也没有指向
   PatchNCE/SB 梯度方向更优。**在禁止加 seed、且单 seed 噪声≈2 dB 的前提下，不建议现在
   发明并训练新方向**——会退化为“人肉超参”。

建议：当前证据链最诚实的下一步不是再跑最小 GPU，而是**承认 hand-tuned 25 / strength=0.5
已接近当前可测信息的上限**；若必须推进 HJ 机制，需先补 seed（当前被约束禁止），否则任何
单 seed “优化”都无法区分真实效应与噪声。
