# Archive

## 接任摘要

| 问题 | 回答 |
|---|---|
| 是什么 | 保存仍需追溯但已被证伪、取代或退出当前入口的历史材料。 |
| 当前结论 | 只读考古层，不参与候选注册、当前状态或论文数字更新。 |
| 时间线位置 | 主要覆盖 T0–T4，也保存 T5 前后的旧 prompt/布局。 |
| 先看哪里 | [早期搜寻](./early-search/README.md) 了解研究起点；其它子目录只按溯源需要进入。 |

历史内容只读保留，用于追溯，不参与当前状态计算：

- `early-search/`：早期路线与证伪历史；
- `prompts/`：旧服务器执行 prompt；
- `superseded/`：被后续裁决替代的计划/分析；
- `legacy-layout/`：迁移前模块入口说明；
- `research-history/`：后续可接收阶段性旅程与上下文快照。

当前入口始终是仓库根 README 和 `decisions/CURRENT.md`。
