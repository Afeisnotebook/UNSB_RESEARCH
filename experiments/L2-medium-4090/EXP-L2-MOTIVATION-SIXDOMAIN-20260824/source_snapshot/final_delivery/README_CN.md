# 六域扩大版共享桥相位实验

本目录回答两个问题：为什么上一版只有五域，以及怎样把“不同域落在不同 task-specific epoch”提升为一个更有统计含义的量。

## 为什么上一版是五域

原始项目一直有六域，第六域是 `RainDS-syn`。上一版五域来自 2026-08-24 基线重启时的人为冻结：为了不把早期六域结果与后续五域统计拼成一个总体，正式头图沿用了五域子协议。它不意味着 RainDS-syn 缺数据或被科学否决。本地原始池中 RainDS-syn 有 200 对身份，旧冻结视图也完整保留了 100 train + 80 discovery + 20 confirmation。

本轮不会把 RainDS-syn 接到旧五域 checkpoint 上，而是从头训练六个 Single 和一个六域 AIO。

## 数据为什么定为 120/80

RainDS-syn 只有 200 个源身份，因此六域均衡设置的上限由它决定。本轮每域使用 120 个 trainA、120 个 unpaired trainB 和 80 个 held-out A；trainA 与 held-out A 严格不重叠。相较上一版 100 train + 60 个分散在三轮中的观测身份，训练覆盖增加 20%，最终统一观测集增加到 80 图/域，并恢复第六域。

扩大样本的目的只是降低图像抽样噪声、提高域覆盖，不允许按“图是否更明显”选择样本。

## 更深的统计对象

离散有效年龄仍用于直观展示，但主量改为 **交叉拟合共享时钟遗憾**：

`G(t)=min_c (1/D) Σ_d [K_d,t(c)-min_e K_d,t(e)]`。

其中 `K_d,t(e)` 是 AIO e1 与域 d 的 Single age e 之间的互易条件核方向距离。`G(t)` 衡量：若所有域被迫使用同一个任务相位 c，相比每个域各自选择最相容相位，会额外支付多少条件核错配。

为避免在同一批图上选谷底又评价谷底，每域 80 张图在效应读取前哈希分成 40/40 两折；A 折选择共享/域专用时钟，B 折评价，随后交换并平均。5000 次 bootstrap 每次都重新拟合时钟。

第二个量是 bootstrap 相位分布之间的 1D Wasserstein barycenter energy。它使用完整的 argmin 抽样分布，不引入 soft-min 温度，用来区分“域相位真的不同”和“谷底只是不稳定”。

完整冻结定义见 `SIXDOMAIN_PHASE_FROZEN_PROTOCOL.json`。
