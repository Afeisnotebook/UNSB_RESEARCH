# CAND-XXX candidate template

## 接任摘要（复制后必须填写）

| 问题 | 回答 |
|---|---|
| 是什么 | 候选的核心对象、与 plain/canonical 的最小差异。 |
| 当前结论 | `PROPOSED/IMPLEMENTED/DEVELOPMENT_FROZEN/CLOSED/CONFIRMED`，同时写证据边界。 |
| 时间线位置 | 从哪个 MOT/失败路线形成，在哪个阶段被推进或关闭。 |
| 先看哪里 | spec → lineage → 源码 → EXP index → DEC index。 |

新候选必须包含 `candidate.json`、`LINEAGE.md`、冻结 spec、实现/测试位置、`EXPERIMENT_INDEX.md` 和 `DECISION_INDEX.md`。公式或行为改变时新增 `ITER`，不得覆盖旧版本。
