# Handoffs

## 接任摘要

| 问题 | 回答 |
|---|---|
| 是什么 | 面向新同事/新任务的稳定交接入口索引。 |
| 当前结论 | 根目录接任指南已承担当前 handoff；本目录暂不复制长 prompt 或运行中状态。 |
| 时间线位置 | T8 仓库生命周期化后启用。 |
| 先看哪里 | [接任指南](../../TAKEOVER_GUIDE_CN.md) 和 [总时间线](../../project/TIMELINE.md)。 |

新任务/新同事应从根 README、PROJECT_STATE、CURRENT decision、相关 candidate README 和 experiment IDs 接管，不再依赖散落的长 prompt。
